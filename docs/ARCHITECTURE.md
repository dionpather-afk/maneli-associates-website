# Maneli Associates — Architecture & Build Specification

Version 1.0 | TLC demonstration | 16 November 2026

## Conceptual architecture
Audience: individuals, close corporations, private companies, non-profit organisations and existing clients. Outcomes: explain services, build trust using verifiable information and encourage contact.

## Logical architecture
Pages: Home, About, Services, Insights (proposed), Contact. Shared components: responsive navigation, service cards, contact links and enquiry form. A privacy notice is required before production.

## Physical architecture
Source: dedicated GitHub repository. Preview: GitHub Pages. Production: static files uploaded to Xneelo only after written approval. Wix Editor excluded. Runtime: plain HTML/CSS/JavaScript, no database or server runtime.

## Form specification
Full name, email, optional phone, service and message. Browser validation only; nothing is sent or stored. Production needs an approved secure endpoint, spam protection, privacy notice, data retention rules and POPIA review. Do not request sensitive documents through the public form.

## Design
Proposed deep teal, muted gold and ivory palette. Official logo and brand colours have not been verified.

## Release gates
Client approval, official logo/brand, approved copy, verified contact details, photo permissions, secure working form, POPIA, HTTPS, domain, accessibility, performance, SEO, backup and rollback plan.
